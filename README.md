# cybersecurity-skill-checker-mini

A command-line tool that checks if a given list of cybersecurity skills is mapped to the MITRE ATT&CK framework, providing a quick assessment of skill proficiency.

> This tool provides a simple yet effective way to assess a person's cybersecurity skills against industry standards, helping individuals and organizations identify gaps in their knowledge.

## Features

- Contains the main function to check skills against the MITRE ATT&CK framework
- Contains tests to verify the functionality of the cybersecurity skill checker tool
- Verified by tests: The tests will verify that the tool correctly identifies skills mapped to the MITRE ATT&CK framework and handles various edge cases.

## Requirements

- Python 3.11+
- Stack: python, pytest

## Install

```bash
git clone <this-repo>
cd cybersecurity-skill-checker-mini
python -m venv .venv
# Windows: .venv\Scripts\activate
source .venv/bin/activate
pip install -r requirements.txt
```

## Usage

```bash
python -m pytest
```

Example output:

```text
```
Checking skills against MITRE ATT&CK framework...
Skill 'Network Security' is mapped to ATT&CK Technique T1105: Exploitation of Default Credentials.
Skill 'Vulnerability Assessment' is mapped to ATT&CK Technique T1086: Exploitation of Software Vulnerabilities.
```
```
